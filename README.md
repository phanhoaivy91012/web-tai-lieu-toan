# 📚 Hệ Thống Quản Lý Tài Liệu & Bài Giảng Toán - Thầy Phan Hoài Vy

Hệ thống học tập, lưu trữ bài giảng HTML, tài liệu PDF/Word và làm bài tập rèn luyện trực tuyến dành cho học sinh 3 khối (10, 11, 12).

## 🚀 Tính năng chính
1. **Tab 1 - Bài học HTML:** Hiển thị bài giảng tốc độ tức thì (0 giây chờ), hỗ trợ Giáo viên Bật/Tắt bài học và Bật/Tắt hiển thị đáp án theo thời gian thực.
2. **Tab 2 - Tài liệu:** Quản lý tài liệu PDF/Word từ Google Drive theo từng khối lớp.
3. **Tab 3 - Bài tập rèn luyện:** Học sinh làm bài trắc nghiệm trực tuyến không cần tài khoản, tự động chấm điểm và ghi nhận danh sách điểm cho Giáo viên.
4. **Tab 4 - Thông tin:** Cập nhật lịch học và thông báo mới nhất từ Giáo viên.

## 🛠️ Công nghệ sử dụng
* **Frontend:** React + Vite + Tailwind CSS (Tối ưu hiển thị trên Điện thoại, Máy tính bảng và Máy tính).
* **Database & Auth:** Supabase.
* **Lưu trữ tài liệu:** Google Drive.
